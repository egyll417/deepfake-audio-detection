
### Model Description

# Data
My model utilized pre-processed LFCC (Linear Frequency Cepstral Coefficients) features, including delta and delta-delta coefficients, provided in the dataset. Each sample is a torch.Tensor of shape [180, 321], representing the 180 time frames and 321 feature dimensions, and I didn't do any additional data augmentation beyond this.

# Model
I implemented a 2D Convolutional Neural Network (CNN) that treats the LFCC feature matrices almost like images, in order to capture local spectral patterns across time.
- Convolutional Layers: The network contains two main convolutional blocks. The first layer used 16 filters with a 3x3 kernel, followed by BatchNorm2d for internal normalization and a ReLU activation function. The second block increases the depth to 32 filters with similar normalization and activation.
- Pooling: Then after each convolutional block, comes a 2x2 MaxPool2d layer to reduce spatial dimensions and provide translation invariance.
- Global Aggregation: To handle variable-length inputs and condense the rmation, an AdaptiveAvgPool2d layer reduces the final feature maps to a fixed 4x4 size.
- Classification: The final output is generated by a single Linear (fully connected) layer that maps the flattened feature vector to a single logit value.

# Loss
The model was optimized using BCEWithLogitsLoss, which I find is pretty good for binary classification tasks. This loss function combines a Sigmoid layer and the Binary Cross Entropy loss, providing better numerical stability during the training process.

# Others
Optimizer: Training was performed using the Adam optimizer with a learning rate of 0.001.

Performance: The model was trained for 12 epochs, with the training loss decreasing from 0.3111 to 0.0602, which I believe indicates strong convergence.
